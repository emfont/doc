<Steps>
	<Step>
    ### 載入 emfont
    首先，請在你的網頁中載 emfont：

    ```html
    <script src="https://font.emtech.cc/emfont.min.js"></script>
    ```

    要放在 `<head>`、`<body>`、~~`<footer>`~~ 都行。幾 KB 而已，你開心就好。

    <Callout type="info">
        這個 script 是無阻塞的，所以不會阻礙頁面載入。
    </Callout>
    </Step>

    <Step>

    ## 選擇字型

       給要設定字體的 HTML 元素加上字體專屬的 class 即可。

```html
<p class="emfont-jfopenhuninn">
    這個段落使用了 jf-openhuninn-2.0 字型。
</p>
```
 </Step>

    <Step>
        ### 啟動

        在 HTML 載入完之後 (如 `<body>` 的最後面) 啟動即可。

        ```html
        <script>
    emfont.init()
</script>
```

        就是這麼簡單。
    </Step>
</Steps>
